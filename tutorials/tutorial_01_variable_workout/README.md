# Tutorial 1: Variable Workout

This tutorial introduces R variables and data types. You will create variables, use them in expressions, and inspect the results.

## Setup Instructions

1. Navigate to this directory:

   ```bash
   cd tutorials/tutorial_01_variable_workout
   ```

2. Run the program in Rstudio. Or, you can run it from the command line with the following code.

   ```bash
   Rscript variables.R
   ```

## What You'll Learn

- Creating numeric, character, and logical variables
- Assigning values with `<-`
- Updating a numeric variable with arithmetic
- Transforming text with `toupper()`
- Reversing a logical value with `!`

## Tasks

Complete all `TODO` sections in `variables.R`:

1. Create three variables using values that describe you.
2. Use each variable in a new expression or function call.
3. Add and use one descriptive variable of your own.

## Tips

- Numeric values do not use quotation marks: `minutes <- 20`
- Character values use quotation marks: `topic <- "visualization"`
- Logical values are uppercase: `has_experience <- TRUE`
- R prints `NA` for the provided placeholders. Replace each placeholder before finishing.
- Test your code frequently within RStudio or at the command line with `Rscript variables.R`.
